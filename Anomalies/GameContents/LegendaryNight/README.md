# 传说之夜游戏内容

祭坛物品与图格、坠星精华、星星之神的记忆、钱币袋及叩星属于始终编译的模组主内容。祭坛、精华、召唤物和钱币袋使用 `GameContents.LegendaryNight` 本地化分类；叩星沿用 `GameContents` 分类。

移除骷髅王目录时，祭坛仍可放置，精华、召唤物和钱币袋仍存在，钱币袋仍可开启；祭坛不会激活。仪式、激活音效及祭坛仪式接入留在骷髅王 `LegendaryNight/Summoning`，通过可选部分类方法连接。关闭传说之夜 Boss 开关时同样不激活祭坛。

祭坛与召唤物保留原配方。坠星精华由普通超凡骷髅王掉落，钱币袋由传说之夜骷髅王掉落；两者的掉落入口均要求 骷髅王模块存在。内容内部名称不变，保留原有存档标识。

## 叩星 / Starfall Knocker

物品及两个弹幕属于模组主内容，本地化分类均为 `GameContents`。面板基础伤害 750，近战伤害，不设合成或掉落入口。

按住左键蓄力 300 游戏帧（正常速度下 5 秒），允许移动、跳跃、按光标转身。蓄满后可无限保持；提前松手、切换物品、死亡或失去使用能力会取消。攻速不改变蓄力和动作时钟。

当前为 2D 攻击：按光标方位优先下砸（前方上侧至右下 45 度），其余方位使用上挑。蓄力统一为向后下方约 20 度的后拖姿态，锤头保持下砸朝向；上挑释放后前 4 帧平滑翻面。下砸从后拖位置经背后向上抡起，上挑从后拖位置向前抡出，松手锁定方向，18 帧完成挥击。武器仅在玩家持有物层绘制，前手覆盖锤柄；锤头拖尾每帧采样 64 次，保留约 7 帧并加宽光晕。沿锤头扫掠顺序寻找首个可命中的敌怪，命中即停锤并在该次扫掠的黄色锤面中心生成星爆；挥空则在挥击结束时于锤头位置生成同等伤害的星爆，地形不阻挡。保留 750 基础伤害、直击与星爆叠加、完整圆形星爆效果及金色名称。

持有者负责鼠标、松手、生成星爆和友方命中；其他端根据阶段、时钟、方向预测动作。阶段、时钟和挥击方向使用原生 ai，方向使用 velocity；蓄势插值向量通过成对 ExtraAI 同步，初始化沿用实体生成 Action。专用服务器不访问绘制资源。

`StarfallKnockerGeometry` 保存武器参数、2D 挥击轨迹和纹理仿射变换。武器通过 SpriteBatch 绘制，翻面仅改变锤柄横向缩放，不使用深度、透视或细分网格。圆形星爆的纯绘制、Bloom 和屏幕反馈位于 `Graphics/Starburst`，通过 `IStarburstImpactSource` 查询实体，不引用 Boss 类型；骷髅王保留自己的时钟、伤害及圆环校准。共享音效位于 `Assets/Sounds/Starburst.ogg`，反馈着色器位于 `Assets/Effects/Common/StarburstRadialBlur.fx`。

名称行与钱币袋共同调用 `GoldItemNameDrawing`，使用相同金色 shader 参数，同时免除普通异象稀有度名称 shader；关闭 shader 时沿用默认名称绘制。

游戏内验收重点：300 帧边界、切换与死亡取消、快速转身、正反重力、不同缩放、移动中释放、直击与爆炸双命中、密集与共享生命 NPC、专用服务器和中途加入。离线模拟及 GPU 绘制检查不能替代这些验收。

黄色锤面锚点为贴图坐标 (158, 98)，装饰星星 (128, 64) 仅保留为原有挥动轴参考。碰撞扫掠、星爆、蓄力光效与拖尾统一使用锤面锚点经过武器二维变换后的坐标，翻面时随锤面移动。锤面上七股金白至金橙火流向运动后方汇聚，挥击轨迹内三股流火与宽光晕组成拖尾；使用现有 Bloom 纹理和 LDR 加色绘制，不依赖 shader 开关，不新增网络字段，专用服务器不更新火焰视觉缓存。

武器星爆自身实现 IOverlaySource 与 IOverlayDrawable，由统一遮罩管理器在 RenderLayers.All 阶段收集并以 OverlayPriority.Attack 绘制，位于前景液体之后、竞技场暗幕之前；弹幕自身的 PreDraw 不绘制，避免重复提交。边界、本体和 Bloom 一起进入该阶段，不依赖 Boss 模块或单独遍历弹幕的 Overlay。
