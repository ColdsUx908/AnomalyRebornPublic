# 史莱姆王

以跳跃、快速跳跃与传送追击玩家，宝石实体提供各自的攻击与强化。Ultra 包含低血量转阶段及彩虹宝石相关战斗。

## 启用条件与依赖

属于始终编译的模组主内容，运行时要求异象模式及 `AnomalyBossChangeToggler.KingSlime`。逐项开关默认 true。开关定义和公共边界见 [Boss 索引](../README.md)。本项目实现战斗行为，可选灾厄的接入以对应兼容回调为准。

## 代码导航

- [KingSlime.cs](KingSlime.cs)：阶段、参数、状态属性、绘制和锁血。
- [KingSlime.AI.cs](KingSlime.AI.cs)：初始化、阶段分派、跳跃与传送。
- [JewelHandler.cs](JewelHandler.cs)、[JewelNPC.cs](JewelNPC.cs)：本 Boss 宝石调度和基类；各颜色宝石在同目录独立实现。

## 状态、资源与修改约束

宝石主人引用及存活状态由主体属性统一访问；宝石不得依赖史莱姆皇后的同类实现。检查 Ultra 锁血、宝石死亡、传送隐藏期间的碰撞和退场清理。

状态布局和变化标记以主文件语义属性为准。服务器负责权威切换和生成，客户端按同步状态表现；不要将仅绘制的缓存加入网络快照。专属资源及实体留在本目录，公共材质与效果通过统一资源提供者访问。

## 修改与验证

执行 [Anomalies 构建检查](../../README.md)和 [Boss 隔离检查](../README.md)。游戏内覆盖普通异象、Ultra、适用的特殊种子、完整阶段切换、死亡/退场及多人中途加入；检查无灾厄时的行为和资源加载。构建及静态检查不代表完成游戏内验收。
